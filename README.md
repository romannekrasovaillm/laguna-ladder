# Лесенка Лагуна — контур ревизии доменной модели

Витрина контура: как устроена ревизия компактной доменной языковой модели, которая
проходит цикл **CPT → SFT → Agentic-RL** с доказуемыми замерами на каждой стадии.
Схема выше — исходник, а не картинка: она собрана из типизированного JSON-IR
детерминированным компилятором (`diagram/laguna-ladder.architecture.json` → SVG),
поэтому её можно версионировать, проверять и сравнивать как код.

> Состояние на 25.09.2026 (CPT пройдена, SFT пройдена 24.09.2026, **точка решения не пройдена**: замер с судьёй и RL-стадия не сняты, RL не начата). Схема отражает **архитектуру процесса**; числовые метрики —
> агрегаты стадий. Что именно не публикуется и почему — раздел «Границы» ниже.

## Стадии

| Стадия | Что делает | Состояние |
|---|---|---|
| **CPT** (continued pretraining) | доменная адаптация базовой модели `Qwen2.5-0.5B` на замороженном миксе корпуса (9776 шагов) | пройдена: язык сохранён (K1 ×0.98, K2 ×1.07 от собственной базы при потолке 2×), домен выучен (отношение к базе < 1) |
| **SFT** (supervised fine-tuning) | формат, агентное поведение, язык рассуждения; 66157 шагов на нормализованном наборе | **пройдена** 24.09.2026: 66 157/66 157 шагов, 74,5 ч, код возврата 0, вход подтверждён прибором (объявленный набор = прочитанный, 44 105 примеров, совпадение хеша). Дефект формата, на котором стадия останавливалась ранее (ADR-050: 44 % ходов в бюджете, 30.8 % — внутри незавершённого `tool_call`), вылечен режимом: на пониженном пике LR усечения **0.096 против 0.298** (p = 2.5·10⁻⁴). **Но приёмка не снята:** в объявленной цепочке стадий стадии замера с судьёй нет, RL не начат — точка решения не пройдена |
| **Agentic-RL** | обучение в средах с верифицируемыми задачами | не начата: пул задач и среды готовятся; ось переведена на награду по состоянию среды |

## Приборы и гейты

- **Приборы.** PPL-пробы по двум независимым компонентам общего языка (в жанре реплея и вне
  обучающего распределения), доменный набор v3, генеративные пробы формата и агентности,
  штатный режим декодирования (запрет повторов n-грамм) — единый для всех сравнений.
- **Гейты.** Язык: обе компоненты в потолке 2× **собственной** базы. Домен: отношение к базе < 1.
  Агентность: измеренная доля самостоятельных вызовов инструмента. Ресурс: одна
  тренировочная нагрузка на стенд, объявленный хозяин окна. Доказательства: манифест
  прогона с хешами, чек-лист завершённости дельты, отдельный трек решений (ADR).
- **Ось успеха одна:** направление `eval(RL) > eval(SFT)` на одном сиде, с порогом,
  объявленным **до** замера; при одном сиде статистика (std, k-из-k) не считается.

## Что делает контур воспроизводимым

1. **Решения раньше реализации.** Каждое архитектурно значимое изменение — записанное
   решение (контекст → решение → альтернативы → последствия → обратимость) до кода.
2. **Критерии до замера.** Пороги и стоп-условия фиксируются заранее; подмена правила
   после получения чисел запрещена.
3. **Факт первичен.** Манифест прогона несёт хеши данных и состояния репозитория;
   производные сводки не подменяют носитель факта.
4. **Код возврата — не доказательство.** Дельта принимается по наличию артефакта,
   финального коммита, пройденного гейта и машинного контракта результата.

## Результаты стадий (агрегаты)

Числа — отношения к **собственной базе** той же модели (`Qwen2.5-0.5B`), снятые одним прибором и одним режимом декодирования. Абсолютные значения PPL не публикуются: это агрегаты, а не измерения по конкретным документам.

| Стадия | Состояние | Общий язык (K1, жанр реплея) | Общий язык (K2, вне распределения) | Домен | Примечание |
|---|---|---|---|---|---|
| База `Qwen2.5-0.5B` | исходная точка | 1.00 | 1.00 | 1.00 | точка отсчёта |
| **CPT** | пройдена (9 776 шагов) | **×0.98** (лучше базы) | **×1.07** | **×0.75** (выучен) | оба языка в потолке 2×, домен ниже базы |
| **SFT** | пройдена (66 157 шагов, 24.09.2026) | ×0.98 | ×1.07 | ×0.35 по калибровочной шкале монитора; **решающий набор v3 для этой стадии не снят** | вход подтверждён прибором (объявленный набор = прочитанный); усечения 0.096 против 0.298 у прежнего входа (p = 2.5·10⁻⁴); язык на пробе n = 5: 0.451 (середина) → 0.371 (финал) против 0.888 у базы — направление не установлено, нужен замер n ≥ 100; **приёмка не снята** (в цепочке не было стадии замера с судьёй, RL не начат) |
| **Agentic-RL** | не начата | — | — | — | ось переведена на граундинг (см. ниже) |

**Почему это проверяемо, а не «нам кажется».**

- **Прибор тождествен.** Базы воспроизведены повторным замером с расхождением 0.0 при допуске ±1e-4: сравнение идёт с базой, снятой тем же прибором, а не с числом из чужого отчёта.
- **Один носитель версии прибора.** У каждого прибора есть реестр редакций (sha256, дата, коммит); страж механически сверяет реестр, снимок, дерево и историю git — правка прибора не может незаметно разойтись с цитатами.
- **Данные воспроизводимы пересборкой.** Пул задач пересобирается из источников в отдельный каталог и совпадает с рабочим **побайтово** (`cmp` без вывода), детерминизм подтверждён двумя разными хеш-сидами.
- **Критерий фиксируется до замера.** Пороги стадии и стоп-условия объявляются заранее; изменение критерия после получения чисел запрещено — это правило зафиксировано решением, а не намерением.
- **Трассируемость.** Каждый инвариант архитектуры либо привязан к механическому правилу, либо помечен как непроверяемый **с указанием, при каком условии пометка снимается**.

## Границы: что не публикуется

Витрина показывает архитектуру и агрегаты. Внутри периметра остаются:

- доменный корпус и его срезы/кэши, цитаты концептов;
- веса и чекпойнты модели;
- отчёты и доказательства прогонов (evidence), карточки корпуса и наборов;
- данные SFT/RL-наборов;
- всё, что позволяет восстановить содержимое документов.

Это не недоработка витрины, а **принятый режим**: доменная часть работает во внутреннем
контуре (`internal_only`), публикация артефактов — только по перечисленному выше списку
и решением владельца. Основания: ADR-005 (режим внутреннего использования) и
ADR-048 (граница публикации витрины). Витрина обновляется вручную и не является
источником истины: при расхождении верен внутренний контур.
